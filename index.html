01 / GPU COMPUTING↗

GPU CNN Inference
& Kernel Fusion

Batched convolution for a modified LeNet-5 on Fashion-MNIST, with CUDA kernels that bring input unrolling, matrix multiplication, and output permutation together.

87.14%CPU-reference accuracy matched
10,000Evaluation images
  • CUDA C++
  • NVIDIA A40
  • Nsight
Implementation notes +
  • Implemented im2col input unrolling and shared-memory tiled matrix multiplication.
  • Fused unrolling, multiplication, and output permutation into one kernel.
  • Profiled CPU/GPU variants with gprof, Nsight Systems, and Nsight Compute.
  • Measured 56.70 ms combined kernel time for the direct-convolution baseline on NVIDIA A40; this is a baseline measurement, not the fused-kernel timing.
